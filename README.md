# Köprü — sürümler

Köprü uzak bağlantı yöneticisinin (RDP, SSH, VNC, Telnet, SFTP, SSH tüneli, PowerShell, web) kurulum dosyaları.

- **Kurulum:** [Releases](../../releases/latest) sayfasından `KopruDesktop-win-Setup.exe` dosyasını indirip çalıştırın.
  Yönetici yetkisi gerekmez; Windows 10/11 x64.
- **Güncelleme:** Kurulu Köprü yeni sürümleri bu depodan kendiliğinden indirir.
- **Tarayıcı eklentisi:** Her sürümde `kopru-extension-*.zip` olarak bulunur.

Dosyalar 7 TEPE Bilişim Sistemleri Tic. Ltd. Şti. adına dijital olarak imzalıdır.
Bu depoda yalnızca kurulum dosyaları bulunur.
